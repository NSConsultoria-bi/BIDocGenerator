PERGUNTAS FREQUENTES

Dúvidas frequentes

Tire suas dúvidas sobre o E-BI DOC Generator e sobre o formato do arquivo de projeto.

01 Qual formato de arquivo devo enviar?

Envie um arquivo .zip contendo um projeto Power BI salvo no formato .pbip (Power BI Project).

Como preparar o arquivo:

  1. Abra seu projeto no Power BI Desktop.
  2. Salve o projeto no formato .pbip.
  3. Localize o arquivo .pbip e as pastas .Report e .SemanticModel geradas pelo Power BI.
  4. Selecione os três itens e compacte-os em um único arquivo ZIP, mantendo-os juntos na raiz do pacote.
  5. Selecione o ZIP no E-BI DOC Generator.

O ZIP deve conter um único projeto, com seu arquivo .pbip e suas pastas .Report e .SemanticModel. Não envie apenas o arquivo .pbip nem um arquivo .pbix. Os nomes podem variar conforme o projeto; mantenha a estrutura original gerada pelo Power BI.

02 O que acontece com meu arquivo?

O projeto é enviado ao backend para validação, análise da estrutura e geração do documento DOCX. O download deve ser disponibilizado após o processamento bem-sucedido.

03 O documento gerado pode ser editado?

Sim. O resultado é um arquivo DOCX que pode ser aberto e editado em um editor compatível, como o Microsoft Word. Se desejar, você poderá exportá-lo para PDF depois.

04 Preciso fazer uma doação para baixar?

Não. O download gratuito está disponível. Se desejar poderá fazer uma contribuição voluntária para geração de novas ferramentas.
